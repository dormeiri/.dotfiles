# Output format

```md
# {Context Name}

{One or two sentence description of what this context is and why it exists.}

## Glossary

**{Term}**:
{A one or two sentence description of the term}

_Avoid_: {Synonym}, {Synonym}
```

- `_Avoid_` only appears under terms that actually have rejected synonyms — don't add it everywhere.
- `{Context Name}` should name the bounded context (e.g. "Orders Service", "Billing Domain"), not just repeat the repo name.
