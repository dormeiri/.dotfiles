# Write Blog Post

Turn an unstructured brain dump into a cohesive blog post. The mess is the input: don't ask the user to organize it first.

## Process

1. Read [VOICE_AND_TONE.md](./references/VOICE_AND_TONE.md).
2. Look for a journey in the material: a shift from one understanding to another. If there is one, shape the post with [STORY_CIRCLE.md](./references/STORY_CIRCLE.md). Not every post needs the full circle.
3. Pick a structure that fits the content, e.g.:
   - Problem → Journey → Results → Lessons
   - Setup → Challenge → Discovery → Application
   - Philosophy → How-to → Reflection
4. Write the post:
   - **Opening:** hook with a recent event or current position, set up a tension or question.
   - **Body:** headers to break it up, varied paragraph length, specific details (tool names, commands, numbers), honest about limitations.
   - **Ending:** tie back to the opening, end with forward momentum or actionable advice.
5. Review against the checklist in [VOICE_AND_TONE.md](./references/VOICE_AND_TONE.md), then show the post to the user and iterate.
